# SFX Asset Wishlist

Use commercial-safe WAV files where possible. Avoid MP3 for source assets if you can.

For the first SFX test, focus on restrained literary ambience and a few clear spot/motion sounds. We are not building a full audio drama yet.

## Asset Rules

- Use commercial-safe licenses only.
- Save files as WAV when possible.
- Keep filenames matching the asset id, e.g. `spot_cat_hiss_small_001.wav`.
- Avoid sounds with music, voices, recognisable dialogue, watermarks, or exaggerated cartoon tone.
- Prefer subtle and realistic over cinematic.
- Note the source/license for every uploaded asset in `assets/sfx/library.json`.
